## Complete incumbent surface

The default regex Unicode feature is a seven-part bundle:

| Feature | Required semantics |
| --- | --- |
| `unicode-age` | Age property and aliases |
| `unicode-bool` | supported binary properties, whitespace, emoji properties |
| `unicode-case` | simple case folding |
| `unicode-gencat` | general categories and Unicode decimal backing |
| `unicode-perl` | Unicode `\d`, `\s`, `\w`, and word boundaries |
| `unicode-script` | Script and Script_Extensions |
| `unicode-segment` | GCB, WB, and SB property lookup |

This full bundle is the ownership boundary. R1 directly exercises simple
folding, Unicode whitespace/digits, Greek script, Unicode and ASCII word
boundaries, and Unicode scalar escapes, but those examples do not authorize a
smaller hand-curated table.

Unicode word boundaries in this contract are the incumbent regex semantics:
they are synchronized with the Unicode `\w` class. They are not claimed to be
the raw UAX 29 Word_Break algorithm. Case-insensitive matching uses simple case
folding. Full folding, such as expanding one scalar into several scalars, is
not claimed.

## Deterministic generation

All 12 enabled table commands are exact and independently checksum-pinned in
the machine artifact. Representative commands are:

```text
ucd-generate age ucd-16.0.0 --chars
ucd-generate case-folding-simple ucd-16.0.0 --chars --all-pairs
ucd-generate general-category ucd-16.0.0 --chars --exclude surrogate
ucd-generate property-bool ucd-16.0.0 --chars
ucd-generate property-values ucd-16.0.0 --include gc,script,scx,age,gcb,wb,sb
ucd-generate script-extension ucd-16.0.0 --chars
ucd-generate word-break ucd-16.0.0 --chars
```

Regeneration is admissible only when:

1. the archive and all 14 input digests match;
2. the generator version and crate digest match;
3. every output byte count and SHA-256 matches;
4. the independent semantic corpus passes;
5. no expected feature, table, or property row is missing.

The current independent regeneration attempt is
`BLOCKED_RCH_PREFLIGHT`. The published source was fetched, but RCH rejected the
probe before starting a compiler and refused local fallback. Consequently this
contract does not call the outputs independently regenerated and does not
authorize ownership or cutover.

## Independent validation

The focused contract checks all frozen source digests, exact feature/table
joins, generation commands, byte totals, dependency checksums, and fail-closed
mutation behavior. With `metrics` enabled it also exercises:

- a code point newly assigned in Unicode 16.0;
- boolean and emoji properties;
- simple sigma folding and the explicit absence of full `ß` to `SS` folding;
- general category, Script, and Script_Extensions;
- Unicode `\d`, `\s`, and `\w`;
- GCB, WB, and SB property values;
- Greek Unicode boundaries and ASCII-only boundary mode;
- rejection of an unknown property.

Run it remotely:

```bash
RCH_REQUIRE_REMOTE=1 rch exec -- \
  env CARGO_INCREMENTAL=0 CARGO_PROFILE_TEST_DEBUG=0 \
  RUSTFLAGS='-D warnings -C debuginfo=0' \
  cargo test -p asupersync --features metrics \
  --test regex_unicode_table_contract -- --nocapture
```

No local Cargo fallback is approved.

## Licensing and update policy

Any copied or regenerated table must retain the Unicode data license and the
generator attribution. The incumbent `regex-syntax` package is MIT OR
Apache-2.0 and carries `LICENSE-UNICODE`; the machine artifact pins the license
bytes and digest.

A Unicode, regex-stack, generator, table, or accepted-surface change invalidates
this packet. Refresh all input/output digests, regenerate all 12 tables from
one UCD version, rerun the semantic and mutation corpus, and remeasure source,
dependency, compile, and release-artifact budgets. Mixed Unicode versions,
partial hand-edited tables, and unknown-property-as-empty-class behavior are
forbidden.

## No-claim boundary

This contract does not authorize removing `regex` or `regex-syntax`; claim an
owned Unicode table; promise full case folding or normalization; prove matcher,
capture, replace, privacy integration, performance, or broad workspace
correctness; treat the blocked probes as size or compile evidence; approve
local Cargo fallback; or claim release readiness or live RCH fleet
availability.
